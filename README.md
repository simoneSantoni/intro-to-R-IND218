# IND218 - Introduction to R

A comprehensive MSc module on R programming for analytics students, covering R fundamentals and the tidyverse ecosystem for modern data analysis and statistical computing.

## Course Overview

This course provides a practical, hands-on introduction to R programming with emphasis on real-world data analysis workflows. Students will master core R concepts and the tidyverse suite of packages for efficient data manipulation, visualization, and statistical computing.

## Module Structure

### 🚀 Module 1: Getting Started with R
- Installing R and RStudio
- R as a Calculator
- RStudio Interface
- R Scripts and Projects

### 📊 Module 2: R Fundamentals
- Data Types and Objects
- Vectors and Data Structures
- Control Structures and Functions
- Working with Files

### 🔧 Module 3: Introduction to Tidyverse
- The Pipe Operator
- Working with Tibbles
- Data Import with readr
- Data Manipulation with dplyr

### 🎯 Module 4: Data Types in Tidyverse
- String manipulation with stringr
- Factor handling with forcats
- Date/time operations with lubridate

### 📈 Module 5: Data Wrangling with dplyr
- Filtering and Selecting data
- Creating and transforming variables
- Grouping and Summarizing
- Joining datasets
- Advanced techniques

### 🧹 Module 6: Organizing Tabular Data with tidyr
- Tidy data principles
- Pivoting between wide and long formats
- Separating and uniting columns
- Handling nested data structures

## Learning Approach

- **Practical Examples**: Real-world datasets and business scenarios
- **Progressive Complexity**: From basic concepts to advanced techniques
- **Modern Best Practices**: tidyverse-focused with reproducible workflows
- **Interactive Learning**: Quarto-based materials with executable code

2. Install R and RStudio

4. Navigate to website/ and run `quarto preview` for local development
